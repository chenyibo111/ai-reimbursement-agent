# 报销单列表页码分页设计

员工报销单列表每页显示 10 条，支持上一页、下一页、选择可见页码及输入页码跳转。当前页写入 URL 的 `page` 参数，刷新与浏览器前进后退仍停留在该页；筛选或清除筛选后回到第 1 页。无效 URL 页码按第 1 页处理；筛选后页码超出总页数时回到最后一页。

Go `GET /api/v1/claims?search=true` 增加可选的 `page`（1 到 10000），按同一筛选与稳定排序执行带 OFFSET 的查询，并继续返回 `items`、`totalCount`、`nextCursor`。页码模式的 `nextCursor` 为空，`page` 与 `cursor`、`countOnly` 不可同时使用。未传 `page` 时维持 Agent 的游标语义。

页码查询在列表频繁新增或删除时可能出现跨页位置移动；此交互用于人工查找已有单据，接受这一代价。页面控件保持现有设计体系及中文文案，键盘可操作，并标记当前页。
